# Runtime 0.15.15

The live ChatGPT account model catalog now reports whether each visible model
can be selected. The `requires_model_opt_in` field is `false` for models the
Runtime accepts by default, `true` when the owner must opt in to an unverified
model, and `null` for models the Runtime refuses. Clients can use this field
to offer choices from the connected account.

Runtime now accepts model catalogs up to 8 MiB. Authorization responses keep
their existing 256 KiB limit.
