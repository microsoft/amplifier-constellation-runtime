# 0.10.2 — Continue work through context refresh and uncertain input recovery

A refreshed room snapshot or compaction can change the local history projection while native steering is waiting for a tool result. Runtime now sends only the new local observations on the existing response chain, preserving accepted input and completed tool effects instead of aborting the turn. Context and turn budgets still apply.

Uncertain earlier inputs stay quarantined and queryable without blocking a new request. The model receives bounded uncertainty metadata and instructions to inspect related effects before acting. Original input is not automatically replayed, and its receipt is not silently acknowledged or marked complete.

Failure telemetry now records bounded model stage, category, and chain state. It excludes provider error bodies, source text, and credentials.

Validation includes native WebSocket refresh/compaction regressions, durable uncertainty tests across providers, and a separate real Instance-to-Runtime recovery fixture covering disconnect and restart with one original tool effect.
