# Runtime 0.15.11

Long Anthropic sessions can now compact a working window after a reply containing
reasoning but no visible text. Previously, a waiting conversation update could
trigger a summary request that the service rejected because its final assistant
message ended with reasoning.

The summary request omits that trailing reasoning, or the final assistant message
when it contains nothing else. Saved history and full-prefix checkpoint binding
are unchanged, as is normal model-request serialization. Successful compaction
continues to use the signed compact window. Pending input stays outside the
summary until it is accepted through the existing input flow.

This patch preserves context thresholds, work budgets, permission checks and
settings-bound checkpoints. It does not change when a turn's first request
compacts or prevent instruction and tool changes from invalidating a saved
compact window. Earlier failed or unaccepted input is not automatically replayed.

The existing native-context regression suite also runs against each release
executable before packaging. Publication does not update an installed engine;
select the new release through the installation's existing update path.
