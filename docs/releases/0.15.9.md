# Runtime 0.15.9

A well-formed request for a tool name that the current session does not offer now
returns an error for that call instead of failing the whole turn. The model can
request a listed tool on its next step, within the existing model, tool and time
budgets. The runtime does not execute or approve the unlisted name, and it never
aliases a suggested name automatically.

GitHub Copilot follows the same path. Its SDK still cannot execute tools; Rust
owns registry lookup, builtin input validation, session mode and permission
checks. Copilot installations must update both the runtime executable and the
matching `bridges/copilot/provider.py` from this release. SDK version and protocol
are unchanged.

This release retains 0.15.8's builtin schema enforcement and engine-authored tool
identity metadata. Clients using that metadata for permission decisions should
continue checking the advertised version and resolved call identity. No existing
permission, command or workspace access is expanded.
