# Runtime 0.11.1

Fixes a live compatibility conflict between OpenAI native steering and automatic
compaction. Responses now uses explicit native compaction only at a settled
socket boundary. Incoming updates wait durably during maintenance, pending
steering stays on its original chain, and maintenance never resets the turn's
model-call budget or replays tool effects.

Provider failures now retain allowlisted error codes and delivery-stage facts
without logging provider error text, source messages, or credentials.

Validation covers input during maintenance, accepted steering before a tool
result, one-write preservation, unchanged call limits, canonical history,
rejection diagnostics, and the actual provider's two-update steering sequence.
