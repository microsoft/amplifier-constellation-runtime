# Native Runtime 0.15.3

MCP tools may return the same JSON result in both a text block and
`structuredContent`. The runtime now sends one copy of those facts to the model
when the text is an exact serialized duplicate from a uniquely matched MCP call.
The original tool result remains unchanged in saved history and ACP receipts.

Distinct text, images, annotations, error flags, unknown fields and private
provider continuation state remain intact. Context budgeting uses the same
projection, including when a native context window is restored. This can avoid
unnecessary compaction without another model request or a summary of the data.
Results with alternate formatting or ambiguous or missing call identity stay
unchanged. Output-only incremental continuations keep both copies when the
matching call is absent from that slice.

Validation includes actual ACP/provider tests for preserved original receipts,
reload without tool replay, and unchanged canonical native checkpoints, plus
Responses, Anthropic, Gemini, Chat Completions and Ollama serialization coverage.
These are local fixture checks. The representation reduction is deterministic;
response latency still depends on the model, context, caching and experience
behavior. No permission, model, endpoint, credential or session migration is
introduced by this release.
