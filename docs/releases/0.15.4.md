# Native Runtime 0.15.4

This release adds native Intel Mac and Windows 11 ARM64 packages alongside Linux x64/ARM64, Apple-silicon Mac and Windows x64. Windows builds include the Visual C++ runtime, so running the executable does not require a separate redistributable, WSL or a development environment.

Every platform runs the runtime tests and protocol/helper/permission fixtures against its actual release executable. Archives contain exact source, architecture and executable identity metadata and SHA256 checksums. Engine behavior, existing session storage, model selection and account boundaries are unchanged from 0.15.3.

These are unsigned native previews. Windows x64 CI uses Windows Server 2025; consumer Windows 11 x64 installation and publisher signing remain separate qualification. Optional bridges and tool programs retain their own dependencies. Instance supplies the independently owned installation and setup experience; this executable does not silently install another engine or modify an existing installation.
