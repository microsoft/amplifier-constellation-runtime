# Runtime 0.15.17

An owner can select a host-managed Codex subscription for the native OpenAI
Responses engine. With hosted image generation enabled, an agent can generate
an image, inspect it, edit it and save the full original by its artifact ID
during an ordinary ACP turn. The host owns sign-in and credential refresh.
Setup requires an explicit account ID and credential file. A same-account
refresh keeps existing sessions usable. A different account cannot receive
their history. See [subscription setup](../chatgpt.md#host-managed-codex-subscription).

Runtime reconciles streamed output with the provider’s final response before
dispatching local calls. After a settled artwork result it can open a fresh
connection with the saved image evidence. If an acknowledged request fails
before any output, Runtime can continue once with local tools. The failed
artwork operation stays unknown. Model-call and local tool-call limits span
the connection change. The subscription route sends no provider-side cap
for hosted calls or output tokens.

Pocket Arcade build 27 exercised generation, inspection, editing and game
publication on the ARM64 handheld on the development candidate. Controlled
tests cover the failure path and account changes. Development-only Codex
sessions created before account binding retain their history and need a new
session to use this release.
