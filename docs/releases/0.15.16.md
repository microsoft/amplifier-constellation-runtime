# Runtime 0.15.16

If an HTTP MCP tool call loses its reply, Runtime records the outcome as
unknown. For the rest of the turn, Runtime permits only distinct, separately
authorized calls to tools that server advertises as read-only. This lets the
agent inspect the result on the same connection. Loading the saved session
preserves the original receipt without replaying the call.

Runtime keeps the MCP session ID established at initialization for subsequent
requests, including cancellation and recovery reads.
