# Runtime 0.11.2

Existing long conversations can continue after enabling native compaction. The
runtime first restores a bounded working view when no native checkpoint exists,
instead of sending the entire saved archive to the provider's compact endpoint.
Producer-declared refreshed snapshots apply on this path too. Full saved history
and existing native canonical windows remain unchanged.

Compaction failures now record the HTTP status and a bounded reason code without
including provider error text or conversation contents.

Regression coverage includes oversized pre-existing transcripts, native-path
snapshot refresh, restart with canonical windows, and private error payloads.
