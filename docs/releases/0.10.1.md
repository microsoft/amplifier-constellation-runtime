# 0.10.1 — Preserve assistant message identity across steering revisions

A steering successor can revise a final answer within the same prompt. Runtime text chunks now retain assistant item identity and available public phase metadata, including session replay; non-Responses backends get a stable identity per model call. This keeps separate answers from becoming one invalid reply.

Validation: real WebSocket/ACP revision and replay regression; Rust tests, provider fixtures, native steering and between-step steering checks.
