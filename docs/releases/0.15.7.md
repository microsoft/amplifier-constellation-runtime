# Native Runtime 0.15.7

HTTPS MCP connections can now use an installation's private certificate authority.
Set `SSL_CERT_FILE` in the Runtime process environment to a PEM certificate bundle;
its certificates supplement the public roots. Certificate and hostname validation
still apply. An unreadable, invalid or empty bundle refuses the connection.

This setting applies to Runtime's HTTPS MCP client. It does not change OS trust,
Instance's context-provider client, model-provider trust settings, or permission
to use a tool. Existing endpoint credentials and tool approvals still apply.

The release packages the merged HTTPS MCP trust fix without changing dependencies,
model settings, saved sessions, work records, or tool interfaces. Disposable TLS
checks cover accepted and refused certificates, hostname mismatch and bundle
errors. A controlled real-component reference also exercises this HTTPS MCP
connection. These fixtures are separate from live-provider or installed-fleet
qualification.

Native downloads retain the existing six-platform packaging. These previews are
unsigned and are not notarized.
