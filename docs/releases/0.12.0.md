# Runtime 0.12.0

The native runtime uses the SDK as its ACP agent endpoint. Model execution, tools, durable sessions, steering and provider behavior remain runtime responsibilities.

The ACP v1 connection uses the official `agent-client-protocol` Rust SDK 5.0.0 through the pinned `amplifier-acp-connection` integration at Constellation revision `e0d6a03fd342b295d349b633d400376efbbe2c40`. The SDK owns protocol framing, request IDs, correlation, cancellation and dispatch. The small integration adds bounded Tokio streams, ordered application observations and a transparent bridge; it is compiled into each independent installation and needs no shared service.

See the [SDK-first contract](https://github.com/microsoft/amplifier-constellation/blob/main/contracts/protocol-sdk.v1-candidate.md) and [integration responsibilities](https://github.com/microsoft/amplifier-constellation/tree/e0d6a03fd342b295d349b633d400376efbbe2c40/crates/acp-connection). Capability extensions still require negotiation; using the SDK does not claim support for every ACP feature or draft.

Validation covers protocol ordering, callback responses, cancellation, uncertain delivery and original-session recovery using disposable peers. Published CI results identify the tested platforms. No provider certification or live-tenant validation is implied.
