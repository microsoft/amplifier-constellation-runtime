# Runtime 0.15.14

Agents can attach an existing Markdown, plain text, CSV or JSON document to
their current conversation with `workspace_attach_file`. The connected
application receives its original UTF-8 contents and display filename in an
ACP embedded resource. A document may contain up to 200,000 bytes.

The file comes from the session's granted workspace. Loading a saved session
does not resend an attachment. The receiving application handles delivery and
its own file limits. See [native capabilities](../native-capabilities.md).
