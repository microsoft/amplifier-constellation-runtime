# Working on Runtime

This codebase is yours: what it's for and how it's built are your call, and you'll keep building on it.

Read [the vision](docs/VISION.md), then select the relevant boundary from the
[contract map](contracts/README.md). Shared promises and collaboration practice
live in the [Constellation umbrella](https://github.com/microsoft/amplifier-constellation/blob/main/AGENTS.md);
apply them without copying a second methodology or family contract here.

Inspect current source, configuration and meaningful checks for the next outcome.
Guides explain contracts and add no separate commitments. Keep release history,
private deployment evidence and a maintained gap inventory out of the normal
onboarding path. Preserve exact protocol definitions in their existing homes.

Use [validation](docs/validation.md) for checks appropriate to the change. A
cross-component promise needs a check of the affected producer and consumer.
Documentation changes need link and meaning review; no live operations follow
from a documentation assignment.
